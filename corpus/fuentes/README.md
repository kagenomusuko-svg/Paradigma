# Fuentes canónicas

Esta carpeta recibe los Markdown íntegros tal como fueron incorporados al corpus.

Reglas:

1. No normalizar estilo ni terminología.
2. No corregir contenido doctrinal o editorial sin documentación expresa.
3. No fragmentar aquí los textos.
4. Registrar una suma SHA-256 de cada fuente.
5. Ante cualquier discrepancia con una copia derivada, esta carpeta prevalece.
