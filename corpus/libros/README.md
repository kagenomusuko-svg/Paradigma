# Copias segmentadas

Esta carpeta contiene las representaciones derivadas del corpus para consulta y análisis.

La unidad ordinaria es el capítulo. Prefacios, prólogos, epílogos, apéndices y glosarios se separan cuando la obra los distingue estructuralmente. Las subsecciones internas permanecen dentro del capítulo.

Estas copias no son canónicas. La fuente íntegra correspondiente en `corpus/fuentes/` tiene precedencia.
